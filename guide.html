01 — THE BASICS 先理解這場旋轉

把陀螺裝上發射器，
拉出你的第一條軌跡。

戰鬥陀螺 X（BEYBLADE X）是以高速對戰為特色的陀螺系列。將陀螺裝上專用發射器，在「3、2、1，Go Shoot！」後同時射入競技盤，透過碰撞、持久力與 Xtreme Dash 展開對決。

本頁是給初次接觸者的快速導覽；實際比賽請依活動主辦方與官方規則為準。

02 — THREE LINES 三種產品線
BX

Basic Line
ベーシックライン

基礎產品線。重量分布較穩定，適合認識 BEYBLADE X 的核心結構與基本玩法。

穩定的起點
UX

Unique Line
ユニークライン

獨特產品線。把金屬重量更多配置到外圍，針對特定性能發揮，讓每顆陀螺有鮮明個性。

性能的個性
CX

Custom Line
カスタムライン

自訂產品線。刀刃由 Lock Chip、Main Blade、Assist Blade 三部分組成，提供更細緻的配置變化。

配置的自由
03 — EXPAND SYSTEM 額外擴充系統

三條路線，
各自延伸。

Expand Blade 是在 BX、UX、CX 基礎上延伸的擴充系統。它不是另一條獨立路線，而是把原本的特性再推進一步。

BX EXPAND將金屬在中央連接，提高整體剛性，讓穩定性再提升。01
UX EXPAND把 Blade 與 Ratchet 一體化，放大 UX 針對特定性能的個性。02
CX EXPAND由原本三件式延伸為四件式，讓 CX 的自訂與組合空間更進一步。03
04 — BUILD YOUR BEY 一顆陀螺怎麼看？
BLADE
RATCHET
BIT

Blade / Ratchet / Bit

BEYBLADE X 的基本組成可以先用三個部件理解：

Blade
上層的主要攻擊與碰撞結構，也最直接影響重量與輪廓。
Ratchet
中段的高度與齒數配置，會改變組合的重心與互動方式。
Bit
底部接觸競技盤的部件，影響移動、攻擊與持久表現；官方也以 Bit 作為類型判定的重要依據。
05 — BATTLE LANGUAGE 四種基本類型
ATTACK攻擊型

主動尋找碰撞，追求瞬間的爆發。

STAMINA持久型

維持旋轉時間，在最後一刻留下差異。

DEFENSE防禦型

吸收與抵抗撞擊，守住自己的位置。

BALANCE平衡型

在多種能力之間取得配置與應對。
